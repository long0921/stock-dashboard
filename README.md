# 全球股市实时监控看板

一个**纯静态**的股市看板：双击 `index.html` 就能用，不需要装 Node、不需要起服务器、不需要改 hosts。

## 一、怎么用

直接双击 `index.html`（或拖进浏览器）。首次加载需要联网取数据，2～5 秒出图。

> 建议用 Chrome / Edge / 火狐等现代浏览器。IE 不支持。

## 二、现在有什么

| 板块 | 内容 |
| --- | --- |
| **全球指数** | A 股（上证/深证/创业板/科创50/沪深300/上证50/北证50）、美股（道指/纳指100/标普500/纳指综指）、韩国（KOSPI/KOSDAQ）、日本（日经225/TOPIX）、港股（恒生/恒生科技）。每张卡片带迷你分时走势；卡片头显示当地时间和开/休市状态 |
| **板块主力资金净流入** | 横向柱状图，红=流入、绿=流出，以 0 为轴左右伸展。可切行业 / 概念 / 地域板块，可切流入榜 / 流出榜 |
| **板块涨跌幅** | 横向柱状图，红涨绿跌，副标注同时显示资金流。可切涨幅榜 / 跌幅榜 |
| **财经快讯 7×24** | 新浪财经全球直播流，命中关键事件（美联储、降准、财报、IPO 等）自动打「重要」标，新消息高亮 |
| **自选股** | 输入 `600519` / `00700` / `AAPL` 回车即可添加，存在浏览器本地，刷新不丢。整行可点，同样打开 K 线详情 |
| **可扩展位** | 预留的坑位，下面第四节讲怎么填 |

### 点开任一指数 / 自选股：详情面板

点指数卡片或自选股整行，会弹出详情浮层，三块内容一起看：

- **K 线**：蜡烛 + 影线，MA5 / MA10 / MA20 三条均线，红涨绿跌；下方**成交量柱**（含 VOL MA5/MA10 虚线，看量能在放大还是萎缩）；再下方是**主力净流入**双向柱（以 0 轴为中心）。鼠标移上去有十字光标和浮层，显示开高低收、涨跌幅、成交量、成交额、换手率、主力净流入。
- **分时**：当日价格线（带面积填充）+ 均价线 + 分钟成交量柱，虚线为昨收，左侧刻度直接是相对昨收的百分比。
- **关键数据**（右侧栏）：分「价格 / 成交 / 资金流向」三组，成交额、换手率、量比、振幅、主力净流入及超大单 / 大单 / 中单 / 小单全在里面。

周期可切：**分时 / 日K / 周K / 月K / 60分 / 30分 / 15分 / 5分**。切周期时，图上方那条**区间统计**会跟着变——区间涨跌、最高、最低、振幅、累计成交额、区间主力净流入，以及这段一共有多少根 K 线。

关闭方式：右上角按钮 / 点浮层外空白处 / 按 `Esc`。

顶栏还有：各市场开休市状态、数据源健康灯、倒计时自动刷新（交易时段 **5 秒**，休市 5 分钟），可手动开关。

> 详情开着时，头部价格和关键数据跟着 5 秒刷新走；**图表按周期节流重绘**（分时 15 秒、分钟 K 1 分钟、日/周/月 K 5 分钟），这样既能跟上盘口，又不会每 5 秒闪一下。

## 三、数据从哪来（以及为什么这么设计）

页面是 `file://` 打开的，浏览器不允许 `fetch` 跨域，所以**全部数据走 JSONP**（`<script>` 标签加载，天然不受同源策略限制）。这是"不用服务器"能拿到实时行情的关键。

| 用途 | 数据源 | 说明 |
| --- | --- | --- |
| 指数 / 个股行情 | 东方财富 `push2`（主） | 数据最全，覆盖日韩 |
| 指数 / 个股行情 | 腾讯财经 `qt.gtimg.cn`（备） | 主源挂了自动降级，但**没有日韩，也没有板块数据** |
| 板块资金流 / 涨跌幅 | 东方财富 `push2` `clist` | 无替代源 |
| 分时走势 | 东方财富 `push2his` `trends2/get`（主）/ 腾讯 `minute/query`（备） | 卡片迷你走势 + 详情分时图；腾讯无均价字段，降级时不画均价线 |
| K 线（日/周/月/分钟） | 东方财富 `push2his` `kline/get`（主）/ 腾讯 `fqkline` + `mkline`（备） | `klt`：101 日 / 102 周 / 103 月 / 5·15·30·60 分钟 |
| 主力资金流序列 | 东方财富 `push2his` `fflow/kline/get` | 主力 / 超大单 / 大单 / 中单 / 小单；**只有东财有，腾讯无替代** |
| 财经快讯 | 新浪财经 7×24 | |

> 腾讯这三个接口的响应不是标准 JSONP 回调，而是 `变量名={json}` 赋值语句——代码用 `_var=` 指定变量名、`<script>` 加载后从 `window` 读回来，同样不受同源限制。降级后 K 线没有资金流区时画布会自动变矮，不留空白。

几个已经踩过并修好的坑，改代码时别踩回去：

- 东财有多个数据节点（`push2` / `82.push2` / `push2delay`），代码会自动轮换，单个节点限流不影响使用。
- **新浪的 JSONP 回调名有字符白名单**，带下划线前缀的名字会被拒（返回 `callback illegal character`），所以新闻请求单独用了纯字母数字的回调名。
- 腾讯各市场字段位置不一样（港股比 A 股多一个时间字段），解析时用「现价 − 昨收 = 涨跌额」的关系自动定位，不能写死下标。
- 新浪 `hq.sinajs.cn` 必须带 Referer，`file://` 下发不出去，所以不能当备用源。

## 四、怎么改 / 怎么加

绝大多数改动**只需要动 `assets/js/config.js`**：

```js
// 加一个指数
core: [{ secid: '1.000001', name: '上证指数' }, ...]
// secid 规则：1.=沪市，0.=深市/北交所，100.=国际指数，116.=港股，105.=美股

// 换板块口径
sectorTypes: [{ id: 'industry', name: '行业板块', fs: 'm:90+t:2' }]  // t:1 地域 / t:2 行业 / t:3 概念

// 调刷新频率（毫秒）
refresh: { trading: 5000, closed: 300000, news: 60000 }

// K 线周期、取多少根、画哪几条均线
periods: [{ id: 'd', name: '日K', klt: 101 }, ...]
klineLimit: 120
klineMa: [5, 10, 20]

// 关掉示例数据兜底（接口挂时不再显示示例数据）
demo: { enabled: false }
```

**加一个新板块**（比如涨跌家数、涨停池、北向资金）三步：

1. `index.html` 里复制一个 `<section class="panel span-4">`，改标题和 id；
2. `assets/js/app.js` 里加一个 `renderXxx()`，在 `refreshAll()` 的 `Promise.all` 里加上它；
3. 需要新接口就在 `assets/js/datasource.js` 加一个请求函数（照抄 `fetchRank` 的写法即可，JSONP 已经封装好了）。

板块之间彼此独立：任何一个取数失败只影响它自己，`safe()` 会兜住异常，不会白屏。

## 五、排障：日韩 / 资金流没数据怎么办

**现象**：韩国、日本分组里指数显示「暂缺」，板块资金流显示「示例数据」，顶栏出现橙色提示「主源不通：日韩指数 / 板块资金流不可用」。

**原因**：只有一个——东方财富 `push2` 这个域名在你当前的网络里访问不了。日韩指数（KOSPI `100.KS11`、日经225 `100.N225`）和板块资金流**只有东财提供**，腾讯备用源没有这两类数据，所以会缺。

**顺带说明**：行情、K 线、分时在东财不通时会自动降级到腾讯（K 线有日/周/月/分钟、覆盖 A 股/港股/美股），所以详情面板一般照样能开；只有**主力资金流序列**（K 线下方那一层双向柱）和**超大/大/中/小单**会显示 `--`，因为它们只有东财提供。

**自检**：在浏览器地址栏直接打开下面这个链接，能看到 JSON 就说明通，打不开就是网络问题（公司网络策略、代理、DNS 都可能拦截它）：

```
https://push2.eastmoney.com/api/qt/ulist.np/get?fltt=2&secids=100.KS11&fields=f2,f3,f14&cb=cb
```

**怎么办**：换网络（手机热点、家里网络）通常就好了。代码侧已经做了能做的：东财三个节点（`push2` / `82.push2` / `push2delay`）自动轮换；个别指数代码取不到时会逐个重取，不会因为一个坏代码拖垮整批。

**关于指数代码**：`config.js` 的 `core` 里放的是已实测可用的代码，`extra` 里的是次要指数，东财未必都有，取不到就显示「暂缺」，删掉即可。

## 六、已知限制

- 日韩指数只有东财提供，东财不可用时这两块会缺（腾讯备源没有日韩数据）。
- 板块资金流、个股资金流序列（主力 / 超大 / 大 / 中 / 小单）只有东财一个源，东财不可用时：板块榜显示内置示例数据并标注「示例数据」（可在 config 里关掉），K 线下的资金流柱不画、右侧资金流组显示 `--`。
- 腾讯降级下的 K 线成交量单位与东财不同（不影响图形比例，只影响 tooltip 里「成交量」的读数口径）。
- 非交易时段数据不跳动是正常现象，休市时刷新频率会自动降到 5 分钟一次。
- 数据仅供参考，不构成投资建议。
